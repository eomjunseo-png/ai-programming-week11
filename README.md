# 성적 관리 프로그램

## 1. 무엇을 하나요 (What)

성적 CSV 파일에서 0~100점 사이의 유효한 점수를 읽고, 잘못된 행은 이유와 함께 기록합니다.

## 2. 왜 만들었나요 (Why)

실제 파일에는 빈칸 · 범위 밖 점수 · 중복 이름이 섞여 있어  
그냥 읽으면 프로그램이 죽기 때문입니다.
동명이인일 가능성이 있으므로 같은 이름은 별도 사람으로 남깁니다.

## 3. 어떻게 실행하나요 (How)

Python 3을 설치한 뒤 프로그램 폴더에서 다음 명령을 실행합니다.

```bash
python load_scores.py scores.csv
```
앞의 `scores.csv`는 읽을 파일 이름이므로 다른 파일을 읽을 때는 해당 파일 이름으로 바꿔 실행합니다.

## 4. 어떻게 테스트하나요

pytest를 설치한 뒤 다음 명령으로 테스트를 실행합니다.

```bash
python -m pytest -q
```

최근 확인 결과: **26 passed, 2 failed**. 실패한 두 테스트는 `test_ai_B.py`에 있으며,
중복 이름을 제외하고 잘못된 헤더를 오류 처리하기를 기대합니다. 현재 `load_scores.py`
명세는 중복 이름을 모두 남기고 헤더를 검증하지 않으므로 기대 동작이 서로 다릅니다.

## 5. 파일 구성

| 파일 | 역할 |
|---|---|
| `load_scores.py` | 성적 CSV를 읽고 유효한 점수와 건너뛴 행을 반환합니다. |
| `bug3_logic.py` | 최고점 계산과 합격자 수 계산 함수가 있습니다. |
| `test_load_scores.py` | CSV 읽기 동작 테스트입니다. |
| `test_ai_A.py`, `test_ai_B.py` | 추가 CSV 동작 테스트입니다. |
| `test_ai_bug.py` | 최고점 및 합격자 계산 테스트입니다. |
| `scores.csv`, `empty.csv`, `weird.csv` | 실행과 테스트에 사용하는 예시 데이터입니다. |
